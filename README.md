# Находка

Учебный проект для начинающего Python/FastAPI-разработчика. Объём бэкенда рассчитан примерно на 7–10 дней при занятиях по 4–5 часов в день. Это ориентир: фактический срок зависит от знакомства с базой данных и авторизацией.

Фронтенд готов: доска объявлений, поиск, фильтры, вход и регистрация, мои объявления, создание и редактирование, закрытие и удаление, отклики. Он использует интерактивные демонстрационные данные. Бэкенд — учебная часть для самостоятельной разработки.

## Запуск фронтенда

Из корня проекта:

```bash
python3 -m http.server 8000 --directory dist
```

Открыть `http://localhost:8000`. Устанавливать JavaScript-зависимости не нужно.

Можно запустить фронтенд и PostgreSQL через Docker:

```bash
docker compose up -d
```

Фронтенд будет на `http://localhost:8000`, PostgreSQL — на `localhost:15432`. В контейнере фронтенда тоже работает демонстрация: подключение к базе будет выполнять ваш FastAPI-бэкенд.

## Демо-вход

Кнопка «Войти как Дима» открывает пример аккаунта. Для проверки двух пользователей через форму:

| Email | Пароль |
| --- | --- |
| dima@example.com | demo12345 |
| anna@example.com | demo12345 |

Регистрация также работает в демонстрации. Аккаунты и объявления хранятся только в памяти страницы и сбрасываются при перезагрузке. Проверка пароля в `demo.js` — часть демонстрации интерфейса. Реальный бэкенд использует Argon2 через `pwdlib`, а вход — JWT через `PyJWT`.

## Подключение своего API

`dist/config.js` содержит `API_BASE_URL`. Пустая строка включает демонстрацию; адрес вашего сервера включает HTTP-адаптер из `dist/api.js`. Токен доступа хранится в памяти страницы. После перезагрузки в API-режиме требуется повторный вход.

Описание результата, стек и формат API находятся в `PROJECT.md`. В `backend/requirements.txt` подготовлен список зависимостей, в `backend/.env.example` — пример настроек. Код бэкенда в этот учебный комплект не включён.
